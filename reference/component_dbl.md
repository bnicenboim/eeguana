# Builds a component.

Builds a component.

## Usage

``` r
component_dbl(values)
```

## Arguments

- values:

  Vector of doubles indicating amplitudes.

## See also

Other component:
[`is_component_dbl()`](https://bruno.nicenboim.me/eeguana/reference/is_component_dbl.md)

## Examples

``` r

Cz <- component_dbl(runif(100, -5))
```
