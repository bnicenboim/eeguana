# Eeguana ggplot themes

These are complete light themes based on
[`ggplot2::theme_bw()`](https://ggplot2.tidyverse.org/reference/ggtheme.html)
which control all non-data display.

## Usage

``` r
theme_eeguana()

theme_eeguana2()

default_theme()
```

## Value

A ggplot theme.
