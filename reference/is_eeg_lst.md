# Test if the object is an eeg_lst.

This function returns TRUE for eeg_lsts.

## Usage

``` r
is_eeg_lst(x)
```

## Arguments

- x:

  An object.

## Value

`TRUE` if the object inherits from the `eeg_lst` class.
