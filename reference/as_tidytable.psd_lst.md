# Convert an psd_lst to a long table in [`tidytable`](https://markfairbanks.github.io/tidytable/reference/tidytable.html) format.

Convert the signal_tbl table from wide to long format.

## Usage

``` r
as_tidytable.psd_lst(x, ...)
```

## Arguments

- x:

  A `psd_lst` object.

- ...:

  unused

## Value

A
[`tidytable`](https://markfairbanks.github.io/tidytable/reference/tidytable.html).
