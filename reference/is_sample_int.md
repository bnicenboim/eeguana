# Test if the object is a sample This function returns TRUE for samples.

Test if the object is a sample This function returns TRUE for samples.

## Usage

``` r
is_sample_int(x)
```

## Arguments

- x:

  An object.

## Value

`TRUE` if the object inherits from the `sample` class.
