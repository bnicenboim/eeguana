# Transforms an object to a eeg_lst

Transforms an object to a eeg_lst

## Usage

``` r
as_eeg_lst(.data, ...)
```

## Arguments

- .data:

  An `eeg_ica_lst` and experimentally an MNE raw signal using
  [reticulate::reticulate](https://rstudio.github.io/reticulate/reference/reticulate.html).

- ...:

  Not in use.
