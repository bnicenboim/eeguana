# Functions to get or set the events table of an eeg_lst object.

Functions to get or set the events table of an eeg_lst object.

## Usage

``` r
events_tbl(.data, ...)

events_tbl(.data) <- value
```

## Arguments

- .data:

  An eeg_lst object.

- ...:

  Not in use.

- value:

  An events table.

## Value

A table.
