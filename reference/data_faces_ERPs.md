# ERPs elicited when one subject saw faces and non-faces objects.

A dataset containing the ERPs elicited when one subject saw faces and
non-faces objects. See also the vignette [Introduction - Manipulating a
clean EEG file exported from BrainVision
2.0](https://bnicenboim.github.io/eeguana/articles/brainvision_files.html).

## Usage

``` r
data(data_faces_ERPs)
```

## Format

An eeg_lst with 2 conditions (faces, non-faces)
