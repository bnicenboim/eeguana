# Convenience function for range subsets

`between` is a thin wrapper for the between function of
[data.table::between](https://rdrr.io/pkg/data.table/man/between.html).
It is equivalent to x \>= lower & x \<= upper when incbounds=TRUE, or x
\> lower & y \< upper when FALSE. In comparison with
[dplyr::between](https://dplyr.tidyverse.org/reference/between.html), it
doesn't loose the class of its argument, and it's more appropriate for
manipulating the column `.sample`. For more information and the
description of the arguments, see
[data.table::between](https://rdrr.io/pkg/data.table/man/between.html).
