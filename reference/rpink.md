# Generates pink noise

Adapted from Matlab code of Smith (2011)

## Usage

``` r
rpink(n, scale = 1)
```

## Arguments

- n:

  number of observations.

- scale:

  scale parameter.

## Value

a vector

## Details

Reference: Smith, J.O. Spectral Audio Signal Processing,
<http://ccrma.stanford.edu/~jos/sasp/>, online book, 2011 edition.
