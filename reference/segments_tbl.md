# Function to get the segments table of an eeg_lst object.

Function to get the segments table of an eeg_lst object.

## Usage

``` r
segments_tbl(.data, ...)
```

## Arguments

- .data:

  An eeg_lst object.

- ...:

  Not in use.

## Value

A table.
