# Test if the object is a component This function returns TRUE for components.

Test if the object is a component This function returns TRUE for
components.

## Usage

``` r
is_component_dbl(x)
```

## Arguments

- x:

  An object.

## Value

`TRUE` if the object inherits from the `sample_id` class.
