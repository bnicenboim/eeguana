# Convert a psd_lst list to a long table in [`data.table`](https://rdrr.io/pkg/data.table/man/data.table.html) format.

Convert the psd_tbl table from wide to long format.

## Usage

``` r
as.data.table.psd_lst(x, ...)
```

## Arguments

- x:

  A `psd_lst` object.

- ...:

  Additional arguments to be passed to or from other methods.

## Value

A [`data.table`](https://rdrr.io/pkg/data.table/man/data.table.html).
