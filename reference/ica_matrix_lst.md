# Function to get the list of mixing and unmixing matrices of an eeg_ica_lst object.

Function to get the list of mixing and unmixing matrices of an
eeg_ica_lst object.

## Usage

``` r
ica_matrix_lst(.data, ...)
```

## Arguments

- .data:

  An eeg_ica_lst object.

- ...:

  Not in use.

## Value

A list.
