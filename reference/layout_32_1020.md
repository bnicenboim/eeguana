# Layout for a 32 electrodes cap at the standard 10-20 system

A dataset containing coordinates of a 32 electrodes mounted in an
elastic cap at the standard 10-20 system (Jasper, 1958)

## Usage

``` r
data(layout_32_1020)
```

## Format

An table with channel names and locations
